# The Chat Place 0.5.1

This pre-release updates chat deletion. Installed copies offer it as an update and keep your sessions and settings.

## Added

- **Delete a Codex chat permanently.** Shift+Delete in the session list, or File, Delete Session Permanently, now deletes a Codex chat started here, as it does a Claude chat. Codex deletes the chat's conversation, along with any subagent chats it started, and they can't be brought back; this works for an archived chat or one whose folder has gone. The Chat Place also deletes what it saved for the chat: its task list, its Allow for This Chat rules and its automatic review history. The confirmation defaults to No; stop or finish its turn first. If Codex no longer has the chat (it was deleted already, say), it just leaves the list and you hear that it was already gone. Restored and kept chats still delete only The Chat Place's copy; deleting an agent conversation keeps its chats. (#634)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
