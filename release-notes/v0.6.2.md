# The Chat Place 0.6.2

This pre-release adds chats on API credits: a Claude or Codex chat can be charged to your own API key instead of your subscription. It also fixes formatted messages going blank on Windows for people who use JAWS. Installed copies offer it as an update and keep your sessions and settings.

## Added

- **Open local files from replies** with **Tools, Links** (Ctrl+L), or activate a file link in
  formatted reading. File links offer **Open** in the default app, **Open containing folder**
  and Copy; code blocks containing a single path offer the file actions too. Relative file
  references use the session's working folder when known. Missing files are copy-only;
  executable, script and shortcut types allow folder access and Copy. The row explains any
  restriction, and safety is checked again before opening. (#253)

**Chats on API credits** (#658, #661, #663, #685)

Setting up:

- **Add your key** in **Tools, API Keys** (Alt+T, P). Under **Provider**, choose Claude (Anthropic) or Codex (OpenAI). Paste the key into the key box and choose **Add Key**.
- **Check the key** with **Test Key** in the same dialog. The test costs less than a cent.
- **Each provider is separate.** Claude and Codex each have their own key, their own spending limits and their own total.

Using it:

- **Start a new chat on API credits:** in **File, New Session** (Ctrl+N), choose **API credits** under **Charge to**.
- **Carry on a chat you already have, on API credits:** open the chat, then choose **Chat, Continue on API Credits** (Alt+C, E). This makes a copy of the chat on API credits. The original chat doesn't change.
- **The copy's first message costs more,** because the whole conversation so far is sent with it.

A new Session list column, Charged to:

- **Every chat you start in The Chat Place says how it's paid for,** in a new Session list column, Charged to.
- **What it says:** "Claude subscription", "Claude API credits", "ChatGPT subscription", "OpenAI API credits" or "Copilot plan".
- **Where it's read:** right after Provider. For example: "testing, Claude, Claude API credits, AIChat, idle".
- **It's shown from the start.** If you've chosen your own columns before, it's added once, after Provider (or after Title, or first, if you've removed those).
- **You can move or remove it** like any column, with **View, Session List Columns** (Alt+V, C).
- **It's left out for chats started outside The Chat Place,** such as in the Claude desktop app or a terminal, because how they're paid for can't be known for sure. It's also left out for agent conversations.

What each chat and each reply cost (#692):

- **A new Session list column, Cost,** says what a chat on API credits has spent in all, for example "$1.42". It's the same figure as "Spent on API credits by this chat" in Properties (Alt+Enter).
- **Where it's read:** right after Charged to. For example: "testing, Claude, Claude API credits, $1.42, AIChat, idle".
- **Codex chats say it as an estimate,** for example "an estimated 3 cents". A price-unknown model says the tokens used instead, for example "cost unknown for 12,400 tokens", never $0.
- **It's left out when there's nothing to say:** chats on a subscription, chats started outside The Chat Place, and chats on API credits that haven't spent anything yet.
- **It's shown from the start.** If you've chosen your own columns before, it's added once, after Charged to. Move or remove it with **View, Session List Columns** (Alt+V, C).
- **Each reply in a chat on API credits ends with what it cost,** for example "Cost: 19 cents". In a Codex chat it's "Cost: an estimated 3 cents", or "Cost: unknown, 12,400 tokens" for a price-unknown model.
- **You see it in the messages list,** at the end of the reply's line, and as the last line when you read the whole message (Enter) or its formatted page.
- **It's kept with the chat,** so it's still there after you restart The Chat Place. It's kept in The Chat Place's own files, never in Claude Code's or Codex's.
- **Copy leaves out the cost line,** so a reply you paste elsewhere doesn't carry it. Exported chats keep it.
- **It's there even if you've turned off hearing the cost** in Tools, Settings. That setting only changes what you hear.

Knowing when you're paying, in an open chat:

- **The window title** says "API credits" after the chat's name, for example "testing, API credits — The Chat Place". It's what Alt+Tab and your screen reader's read-title key say.
- **The message box** is named "Your message, API credits", so you hear it when you Tab to it.
- **In a Claude chat, the status bar** shows what the chat and The Chat Place have spent. It reads, for example, "API credits: this chat $0.42, The Chat Place $12.30 of $20".
- **In a Codex chat, the status bar** shows The Chat Place's estimated priced total and any unpriced token count.
- **Usage and Context (Ctrl+Shift+U) in a Codex chat** gives the chat's figure and what's held.
- **To open Tools, API Keys from the status bar,** press F6 (or Ctrl+9) to reach it, arrow to the API credits part, and press Enter.

Knowing when you're paying, as you send:

- **Before your first message in a chat,** a box asks "Send on API credits?". Enter sends; Escape keeps your message in the message box. It asks once in each chat each time The Chat Place starts.
- **To stop being asked,** clear "Ask before the first API-credit message in each chat" in **Tools, Settings** (Ctrl+Comma), in the API credits group.
- **After you send,** you hear "Sent on API credits to" and the chat's name, then your message, for example "Sent on API credits to testing: Add the totals." It's spoken even if you've turned announcements off, and can't be turned off.
- **When the reply comes,** you hear what it cost, for example "testing replied, 6 cents."
- **To stop hearing the cost,** clear "Give the cost of each API-credit reply" in **Tools, Settings**, in the API credits group.

Spending limits:

- **Each provider has two limits:** one for any one message ($2 to start) and one overall ($20 to start). Change them in **Tools, API Keys**.
- **When a priced message reaches the per-message limit,** it stops partway and says what it cost. You can send another message straight away.
- **When the overall limit is used up,** no more messages are sent on that provider's API credits until you raise the limit or choose **Reset Total** in Tools, API Keys. What you typed stays in the reply box.
- **A message can go a little over a limit,** by the cost of one request to the AI.
- **A price-unknown Codex message can't be stopped at $2,** because its cost isn't known. Instead, each one uses up $2 (or whatever your per-message limit is) of your overall limit, so price-unknown messages still run out your overall limit.
- **When you press Stop in a price-unknown Codex chat,** you hear "cost unknown".

Understanding what you've spent:

- **Every cost The Chat Place shows is its own count, for this copy of The Chat Place only.** It counts what this copy sends, not other computers, other apps, or anything else using the same key.
- **Every cost is an estimate.** A Claude cost is what Claude Code reports for each message. A Codex cost is worked out from OpenAI's prices and the usage Codex reports.
- **Your bill is the final word.** The Claude Console and the OpenAI dashboard, and their billing pages, show what you're actually charged.
- **In The Chat Place:** the **Total** box in **Tools, API Keys**, or **Tools, Usage and Context** (Ctrl+Shift+U) in a chat on API credits.
- **If you've used price-unknown Codex models,** Usage, Properties and the status bar give what's been spent on priced models, then the tokens used on price-unknown ones.
- **The Chat Place counts only its own spending.** The Claude Console and the OpenAI dashboard show everything charged to your account, so their totals can be higher.
- **Tip: make a key just for The Chat Place.** The Claude Console and the OpenAI dashboard both show spending for each key, so they'll show exactly what The Chat Place spent.

How Claude and Codex differ:

- **Claude costs are what Claude Code reports** for each message.
- **Codex costs are estimates.** Codex reports how much it used, not what it cost, so The Chat Place works it out from OpenAI's prices, checked November 19, 2026. Codex costs are always said as "estimated".
- **Codex costs assume OpenAI's standard pricing.** If your OpenAI project is set to use Priority processing, Codex chats cost more than The Chat Place estimates.
- **Codex models with a price:** gpt-5-nano, gpt-5.4-nano, gpt-5.4-mini, gpt-5.4, gpt-5.5, gpt-5.6-sol, gpt-5.6-terra, gpt-5.6-luna, gpt-6-astra, gpt-6-sol, gpt-6-luna and gpt-6.1-sol.
- **Any other Codex model can be used too.** In New Session's model list it says "price unknown".
- **Before the first message with a price-unknown model,** a box warns that The Chat Place can't estimate the cost, so your dollar limits can't stop the message. Cancel is the default. It asks again if you change the model.
- **After a price-unknown reply,** you hear tokens instead of a cost, for example "testing replied; used 12,400 tokens, cost unknown."
- **After restarting the app,** the price-unknown question asks again before sending.
- **In the price-unknown question,** Tab reaches Cancel first, then Send on API credits.
- **Send Now (Ctrl+Enter) in a price-unknown chat** holds another allowance against the overall limit.
- **Release Held in Tools, API Keys** gives inactive unpriced allowances back; their actual cost is unknown and may be more.
- **In New Session's Effort list on API credits,** ultra is not offered.
- **gpt-5.6-sol becomes price unknown at 10:00 UTC on November 29, 2026.** This is a conservative cutoff for the promotion's unspecified November 30 end time.
- **If that price expires during a reply,** the reply continues; Usage shows later tokens as unpriced usage.
- **If a queued message needs the price-unknown question,** it comes back unsent and you hear why.
- **After a stopped or failed unpriced reply,** you hear "stopped" or "failed" and the reported tokens.
- **When a price expires during a reply,** the reply notice says so and counts only the unpriced tokens.
- **When token counts are incomplete,** you hear "at least" or "tokens not reported".
- **For unknown-only spending,** Usage and Properties say "cost unknown".
- **The status bar** gives a short spending total; Usage and Context gives the token details.
- **Claude models:** Fable can be chosen, along with the usual models.
- **Not available in Claude chats on API credits:** claude.ai connectors and Remote Control.
- **Not available in Codex chats on API credits:** web search, connected services, subagents, goals, compaction and Ask Aside.

Also:

- **Your key goes only to Anthropic or OpenAI.** Claude Code and Codex can be set up to send their requests through another server, such as a company proxy, and that server would then see your key. In chats on API credits, The Chat Place overrides that setting, so your key goes straight to Anthropic or OpenAI.
- **If Anthropic or OpenAI refuses your key,** you hear so within seconds.
- **On a Mac,** the first time you send on API credits, the keychain may ask about "security". Choose **Always Allow**.
- **Older releases of The Chat Place don't show chats on API credits** in the Session list.
- **Copilot chats can't use API credits.**

## Changed

- **Subscription chats are checked before sending, not after.** If an API key or another sign-in in a Claude Code settings file or your environment would charge a subscription chat to that key, The Chat Place now stops the message before it's sent. Before, it stopped the chat just after. A sign-in made with `claude setup-token` belongs to your subscription and still works. (#658, #663)

## Fixed

- **Messages no longer open as a blank page that Escape can't close.** On Windows, since Microsoft's WebView2 157 update, closing a formatted page while JAWS was running crashed WebView2. On some PCs every page after that was blank until a reboot. (#693)
  - **WebView2 is now closed only when you exit The Chat Place.** When you close a formatted page, its window is hidden and emptied rather than closed, and the next message you open loads into it. While hidden it holds an empty page, and nothing is on screen or reachable until you open another message.
  - **If the page stops working anyway,** it closes within half a minute and the message opens as plain text. A moment later you hear "The formatted view stopped working. Showing plain text until you restart The Chat Place."
  - **The crash itself is in WebView2,** and it has been reported to Microsoft.

- **Opening a formatted message says less on Windows.** Screen readers no longer say "wxWebView" before the page. (#693)

- **Claude no longer asks you to turn on Claude in Chrome.** Claude in Chrome, computer use and the desktop app's browser pane aren't available in chats The Chat Place runs. Claude used to tell you to turn them on, though no setting does that here. Now it says plainly that they aren't available, and uses what it has, such as web search. This applies to new chats and to copies made with Continue Here, Rewind to Here or Branch from Here. A chat started before this version picks it up once it's compacted. (#319)

- **Stop no longer loses a Send Now message.** If you sent a queued message with Send Now (Ctrl+Enter) and pressed Stop before Claude took it in, it now comes back to the message box. (#663)

- **On a Mac, editing keys work in every dialog.** Command+V, Command+A and the other editing keys were being taken over by a dialog's buttons. (#675)

- **On a Mac, Command+D, Command+P and Command+R no longer press Send, Stop and Refresh** in the main window. Send with Command+Return, stop with Command+Period, and refresh with F5. (#675)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription (or an Anthropic API key, for chats on API credits). For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT (or an OpenAI API key, for chats on API credits). For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
