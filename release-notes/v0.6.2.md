# The Chat Place 0.6.2

This pre-release lets a Claude chat spend prepaid API credits instead of your Claude subscription. Installed copies offer it as an update and keep your sessions and settings.

## Added

- **Chats on API credits.** Add an Anthropic API key in **Tools, API Keys** (Alt+T, P), then choose **API credits** under **Charge to** in New Session or Continue Here. To carry on a chat you already have, use **Chat, Continue on API Credits**, which makes a new chat from it. API Keys also sets your limits: The Chat Place stops API chats once it has spent $190, and any one message at about $5, until you change them. In these chats Fable is offered, and Claude.ai connectors and Remote Control aren't available. You always know: the chat's row and the window's title say "API credits", each message you send is followed by "Sent on API credits" (always said, even when announcements are off), the first in each chat asks "Send on API credits?", each reply says what it cost, and the status bar shows what's been spent. Settings has the question and the cost under **API credits**. On a Mac, the first message on API credits may bring up a keychain question for "security": choose **Always Allow**. Codex and Copilot chats can't use API credits yet. (#658)

## Changed

- If a key in your settings or environment would charge a message to an API key instead of your subscription, The Chat Place now stops it before it's sent, rather than just after. (#658)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip, TheChatPlace-macos-arm64.dmg, TheChatPlace-linux-x64.AppImage and TheChatPlace-linux-arm64.AppImage, with the update feeds. See the [user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
