# The Chat Place 0.6.2

This pre-release adds chats on API credits: a Claude or Codex chat can be paid for from an API key instead of your subscription. Installed copies offer it as an update and keep your sessions and settings.

## Added

**Chats on API credits** (#658, #661, #663)

- **Setting up.** Open **Tools, API Keys** (Alt+T, P). Choose Claude (Anthropic) or Codex (OpenAI) under Provider, paste your key, choose **Add Key**, then **Test Key**. Each provider has its own key and limits.
- **Starting a chat.** In New Session, choose **API credits** under **Charge to**. To carry on a chat you already have, use **Chat, Continue on API Credits** (Alt+C, E). It makes a new chat, and its first message costs more because the whole conversation is sent again. A chat stays on API credits or on your subscription for good.
- **Knowing when you're paying.** The chat's row and the window title say "API credits". The first message in each chat asks "Send on API credits?". Every message you send is said to have gone on API credits, even with announcements off, and each reply says what it cost.
- **Spending limits.** Each provider has two: $2 for any one message and $20 overall, to start; change them in Tools, API Keys.
  - A message that reaches $2 stops partway and says what it cost. You can send again straight away.
  - When the $20 is used up, the message that used it says so. Nothing more is sent on API credits until you raise the limit or choose **Reset Total**. What you typed stays in the reply box.
  - A message can go over a limit by the cost of one request.
- **Your totals.** The Chat Place counts only what it spends. The Claude Console and the OpenAI dashboard show everything on your account, including other apps using the same key, so their totals can be higher. To see The Chat Place's spending there too, make a key just for The Chat Place: both let you create several keys and show spending for each.
- **Claude chats.** The cost of each message comes from Claude Code, so it's exact. Fable is offered; claude.ai connectors and Remote Control aren't. On a Mac, choose **Always Allow** if the keychain asks about "security" on the first message.
- **Codex chats.** Codex reports only how much was used, so costs are estimated from a price table dated November 17, 2026, and are always said as estimated. Only models in that table can be used. Web search, connected services, subagents, goals, compaction and Ask Aside aren't available. Your ChatGPT sign-in is never used for these chats.
- **Also.** Your key is sent only to Anthropic or OpenAI, whatever a settings file says, and a key they refuse is said within seconds. Older releases of The Chat Place don't list chats on API credits. Copilot chats can't use API credits.

## Changed

- If a key in your settings or environment would charge a message to an API key instead of your subscription, The Chat Place now stops it before it's sent, rather than just after. So does a sign-in token in a settings file that isn't your subscription's; one made with `claude setup-token` is your subscription's, and works as before. (#658, #663)

## Fixed

- A message sent with Send Now that Claude hadn't taken in when you pressed Stop now comes back to the reply box, as a steered message does, instead of being lost. (#663)

- On a Mac, Command+V, Command+A and other editing keys now work in every dialog; a button no longer takes them over (#675). In the main window, Command+D, Command+P and Command+R no longer press Send, Stop and Refresh: send with Command+Return, stop a turn with Command+Period, and refresh with F5.

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription (or an Anthropic API key, for chats on API credits). For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT (or an OpenAI API key, for chats on API credits). For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
