# The Chat Place 0.6.2

This pre-release lets Claude and Codex chats spend prepaid API credits instead of their subscriptions. The totals and limits it shows count only what The Chat Place itself spends on your keys. The Claude Console and the OpenAI dashboard show everything charged to your account, including other apps that use the same key, so their totals can be higher. Installed copies offer it as an update and keep your sessions and settings.

## Added

- **Codex chats on OpenAI API credits.** In **Tools, API Keys** (Alt+T, P), choose Codex (OpenAI) under Provider, then add and test a key. It has its own limits ($20 in all and $2 a message to start). Then choose **API credits** under **Charge to** in New Session, or carry on an existing Codex chat with **Chat, Continue on API Credits** (Alt+C, E), which sends nothing until your first message. Costs are estimates, from a dated price table, and are always said as estimated; a model without a price can't be used. A message you stop is counted at most what its last request could have cost. Your ChatGPT sign-in is never used for these chats. Connected services, web search, subagents, goals, compaction and Ask Aside aren't available in them. (#661)

- **Chats on API credits.** A Claude chat can be charged to an Anthropic API key instead of your subscription. Add the key in **Tools, API Keys** (Alt+T, P), which also sets spending limits ($20 in all and $2 a message to start). Then choose **API credits** under **Charge to** in New Session, or carry on an existing chat with **Chat, Continue on API Credits** (Alt+C, E). Every message you send in these chats is said to have gone on API credits once Claude Code has it, even with announcements off: "Sent on API credits to Budget", with your message read back after it as usual. Each reply says what it cost, and so do a message you stop and an Ask Aside answer. Your key only ever goes to Anthropic's API, whatever a settings file says, and a key Anthropic refuses is said within seconds. Older releases of The Chat Place don't list these chats. Fable is offered in them; claude.ai connectors and Remote Control aren't. On a Mac, choose **Always Allow** if the keychain asks about "security" on the first message. Copilot chats cannot use API credits. (#658, #663)

## Changed

- If a key in your settings or environment would charge a message to an API key instead of your subscription, The Chat Place now stops it before it's sent, rather than just after. So does a sign-in token in a settings file that isn't your subscription's; one made with `claude setup-token` is your subscription's, and works as before. (#658, #663)

## Fixed

- A message sent with Send Now that Claude hadn't taken in when you pressed Stop now comes back to the reply box, as a steered message does, instead of being lost. (#663)

- On a Mac, Command+V, Command+A and other editing keys now work in every dialog; a button no longer takes them over (#675). In the main window, Command+D, Command+P and Command+R no longer press Send, Stop and Refresh: send with Command+Return, stop a turn with Command+Period, and refresh with F5.

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription (or an Anthropic API key, for chats on API credits). For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT (or an OpenAI API key, for chats on API credits). For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
