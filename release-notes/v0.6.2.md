# The Chat Place 0.6.2

This pre-release adds chats on API credits: a Claude or Codex chat can be paid for from an API key instead of your subscription. Installed copies offer it as an update and keep your sessions and settings.

## Added

**Chats on API credits** (#658, #661, #663)

Setting up:

- **Add your key** in **Tools, API Keys** (Alt+T, P). Choose the provider, paste the key and choose **Add Key**.
- **Check the key** with **Test Key**. It costs less than a cent.
- **Each provider is separate.** Claude and Codex each have their own key, limits and total.

Using it:

- **Start a new chat on API credits:** in New Session, choose **API credits** under **Charge to**.
- **Move a chat you already have to API credits:** **Chat, Continue on API Credits** (Alt+C, E). It makes a new chat that carries on from the old one. Its first message costs more, because the whole conversation is sent again.
- **A chat can't change later.** Once made, it stays on API credits or on your subscription.

Knowing when you're paying:

- **The chat says so.** Its row in the list and the window title say "API credits".
- **You're asked once.** The first message in each chat asks "Send on API credits?".
- **Every message is announced** as sent on API credits, even with announcements off.
- **Every reply says what it cost.**

Spending limits:

- **Two limits for each provider:** $2 for any one message and $20 overall, to start. Change them in Tools, API Keys.
- **At the $2 limit,** the message stops partway and says what it cost. You can send again straight away.
- **At the $20 limit,** the message stops and says the overall limit ran out. Nothing more is sent on API credits until you raise the limit or choose **Reset Total**.
- **A limit can be passed** by the cost of one request.

Your totals:

- **The Chat Place counts only its own spending.** The Claude Console and the OpenAI dashboard show everything on your account, so their totals can be higher.
- **Tip: make a key just for The Chat Place.** Both consoles show spending for each key, so you'll see exactly what The Chat Place spent.

Claude and Codex differences:

- **Claude costs are exact.** Claude Code reports them.
- **Codex costs are estimates.** Codex reports only what was used, so costs come from a price table dated November 17, 2026, and are always said as estimated. Only models in that table can be used.
- **Fable can be chosen** in Claude chats on API credits.
- **Not available on Claude API credits:** claude.ai connectors and Remote Control.
- **Not available on Codex API credits:** web search, connected services, subagents, goals, compaction and Ask Aside.

Also:

- **Your key only goes to Anthropic or OpenAI,** whatever a settings file says.
- **A key that's refused is said within seconds.**
- **On a Mac,** choose **Always Allow** if the keychain asks about "security" on the first message.
- **Older releases of The Chat Place don't list chats on API credits.**
- **Copilot chats can't use API credits.**

## Changed

- If a key in your settings or environment would charge a message to an API key instead of your subscription, The Chat Place now stops it before it's sent, rather than just after. So does a sign-in token in a settings file that isn't your subscription's; one made with `claude setup-token` is your subscription's, and works as before. (#658, #663)

## Fixed

- A message sent with Send Now that Claude hadn't taken in when you pressed Stop now comes back to the reply box, as a steered message does, instead of being lost. (#663)

- On a Mac, Command+V, Command+A and other editing keys now work in every dialog; a button no longer takes them over (#675). In the main window, Command+D, Command+P and Command+R no longer press Send, Stop and Refresh: send with Command+Return, stop a turn with Command+Period, and refresh with F5.

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription (or an Anthropic API key, for chats on API credits). For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT (or an OpenAI API key, for chats on API credits). For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
