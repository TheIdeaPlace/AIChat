# The Chat Place 0.3.1

An update to 0.3.0, still a pre-release. When released, installed copies offer this update and keep your sessions and settings.

## Added

- **Steer a running turn.** While Claude or Codex is working, press Ctrl+Alt+Enter (Cmd+Option+Return on a Mac) in the reply box to send your message into that turn without stopping it. It takes your message in at its next step and carries on. Ctrl+Alt+Enter on a queued message steers that one. Also on the File menu, as Steer: Send into the Running Turn. (#238, #239, #399)
- **Copilot Sign-in.** Help, **Copilot Sign-in** (Alt+H, O) says whether GitHub Copilot CLI is installed and which GitHub account it's signed in to, and offers to sign in if it isn't. (#391)
- **Changed Files for Copilot chats.** View, Changed Files (Ctrl+Shift+D) now works in Copilot chats, including ones started in Copilot CLI. When a Copilot turn finishes in the chat you have open, the files it changed are listed after the reply. (#352) (#401)

## Changed

- **Updated components.** The formatted message view uses a newer version of the Markdown library it renders messages with, and the build uses newer versions of its tools. Nothing should look or work differently. (#381) (#382) (#383) (#384)

## Fixed

- **Stop in a Copilot chat says what happened.** Stop no longer says Copilot "has already answered" when it can't know that, or warns that Copilot will be closed when nothing will close it. (#386)
- **Stop works as a waiting message starts.** Pressing Stop (Ctrl+Period) just as one Copilot answer ends and your next waiting message begins now stops it, instead of saying there's nothing to stop. (#386)
- **Copilot chats stay in the list while Copilot writes them.** A Copilot chat no longer drops out of the session list for a moment while Copilot is saving it, so your place in the list stays put. (#386)
- **Stop right after sending reaches Copilot.** Pressing Stop (Ctrl+Period) just as a Copilot message goes out now stops the answer. Before, Copilot sometimes kept answering and The Chat Place then closed it, which ended every other Copilot chat's answer too. (#395)
- **Copilot says when it isn't signed in.** Starting or opening a Copilot chat, or sending to one, when GitHub Copilot CLI isn't signed in now says so and points you to Help, Copilot Sign-in (Alt+H, O), instead of only "Copilot couldn't do that." Messages still waiting come back to the message box, unsent. (#391) (#400)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and TheChatPlace-macos-arm64.dmg, with the update feeds. See the [user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, or a Mac with Apple silicon. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
