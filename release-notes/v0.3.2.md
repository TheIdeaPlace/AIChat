# The Chat Place 0.3.2

An update to 0.3.1, still a pre-release. When released, installed copies offer this update and keep your sessions and settings.

## Added

- **Changed Files for Codex chats.** View, Changed Files (Ctrl+Shift+D) now works for Codex chats, including ones started outside The Chat Place. Only completed changes Codex reports are counted. (#411)
- **Copilot in agent conversations.** File, New Agent Conversation (Ctrl+Shift+G) now offers your GitHub Copilot CLI chats started here, and a new Copilot chat, alongside Claude and Codex. A Copilot agent's replies are handed on like the others', with the files it changed in that turn, and its permission requests still come to you through Answer (Ctrl+Shift+A). Copilot doesn't say how much of your plan is left, so automatic hand-offs can't warn you about it: each of its turns uses premium requests. Copilot chats are still a preview, turned on in Settings. (#369) (#412)
- **Send Reply to Another Chat into Copilot chats.** File, Send Reply to Another Chat (Ctrl+Shift+E) can now send a reply into one of your Copilot chats, or start a new Copilot chat with it, and can make a Copilot chat half of an agent conversation. (#369) (#412)
- **Usage and Context in Copilot chats.** View, Usage and Context (Ctrl+Shift+U) in a Copilot chat says how full its context is and how many premium requests the chat has used. It reads Copilot's own log and never starts Copilot. (#369) (#412)

## Changed

- **You can read a steered message.** A message you steer with Ctrl+Alt+Enter now shows at the end of the messages list at once, as "Steering, waiting for Claude" (or Codex), and says where it is as that changes, until the chat's history has it. (#410)

## Fixed

- **Steered messages stay in the chat.** A message Claude took in while it was working now shows in the chat's history, in its place, as one of yours. Before, it wasn't shown at all. (#410)
- **Stopping a Copilot chat says what will happen.** Pressing Stop (Ctrl+Period) again while Copilot is stopping no longer puts off closing a Copilot that ignores it, and Stop no longer warns that Copilot will be closed when your message hadn't gone to it yet: the message just comes back unsent. (#405) (#414)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and TheChatPlace-macos-arm64.dmg, with the update feeds. See the [user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, or a Mac with Apple silicon. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
