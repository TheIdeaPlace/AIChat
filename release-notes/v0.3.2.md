# The Chat Place 0.3.2

An update to 0.3.1, still a pre-release. When released, installed copies offer this update and keep your sessions and settings.

## Added

- **Steer a running turn.** While Claude or Codex is working, press Ctrl+Alt+Enter (Cmd+Option+Return on a Mac) in the reply box to send your message into that turn without stopping it. It takes your message in at its next step and carries on. Ctrl+Alt+Enter on a queued message steers that one. Also on the File menu, as Steer: Send into the Running Turn. (#238, #239)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and TheChatPlace-macos-arm64.dmg, with the update feeds. See the [user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, or a Mac with Apple silicon. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
