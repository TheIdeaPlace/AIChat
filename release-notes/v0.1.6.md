# The Chat Place 0.1.6

An update to 0.1.5, still a pre-release. If you have 0.1.5 installed, it offers this update itself
(Help, Check for Updates asks at once), and your sessions and settings are kept.

## Added

- **Find in All Sessions.** View, Find in All Sessions (Ctrl+Shift+S) searches the messages of
  every session in the list. Enter on a result opens that session at that message. (#109) (#199)
- **Permission mode and effort.** File, Change Permission Mode (Ctrl+Shift+O) and File, Change
  Effort change them for one of The Chat Place's own sessions, from its next turn. New Session
  has an Effort box too. (#189) (#196)
- **Links.** View, Links (Ctrl+L) lists the links in the loaded session, newest first. Enter
  opens one, and Ctrl+C copies it. (#190) (#198)
- **Properties.** View, Properties (Alt+Enter) lists the details of the selected session or
  message. (#214) (#218)
- **Tidy the recent folders.** In File, New Session (Ctrl+N), Delete removes a folder from the
  Folder list. Settings (Ctrl+Comma) sets how many are offered, and Clear Recent Folders (Alt+L)
  clears them. (#215) (#217)

## Changed

- **Last activity follows what Claude is doing.** A session that's working reads "active just
  now", not the time its turn began. View, Session List Columns has a new Started column, for when
  each session began. (#209) (#210)

## Fixed

- **Sharp text at higher display scaling.** At 125% or more, text is as sharp as in other
  apps, and tall dialogs such as New Session no longer run under the taskbar. (#185) (#186)
  (#219)
- **New Session and Continue Here show their fields whole.** New Session's Folder box is as
  wide as the others, and Continue Here shows the start of its title and all of its note. (#178)
  (#208)
- **The session list keeps its width.** It no longer narrows while Claude works or as you move
  between sessions. (#179) (#213)
- **The status bar's buttons show their whole text.** (#175) (#202)
- **Long text no longer runs off the edge of the window.** In Settings, Report a Bug, Session
  List Columns, Usage and Context, and the heading above the messages, long lines now wrap.
  (#176) (#205)
- **A first run says how to start.** With no sessions yet, the messages say how to start one.
  (#182) (#206)
- **Show Tool Activity is set for each session.** Ctrl+T now turns it on or off for the loaded
  session only, and each session remembers it. (#162) (#194)
- **Code blocks keep their outline in High Contrast**, in formatted messages, the user guide
  and exported web pages. (#155) (#188)
- **Report a Bug opens even when Windows can't give its full version.** (#211)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you
exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs
   access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to
   [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

The same files as 0.1.5: TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and
TheChatPlace-macos-arm64.dmg, with the update feeds. See the
[user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and
the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

The same as 0.1.0: Windows 10 or 11, or a Mac with Apple silicon, and Claude Code installed with
its native installer and signed in to a Claude subscription. See the 0.1.0 release notes for the
details.
