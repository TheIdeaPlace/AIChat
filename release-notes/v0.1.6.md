# The Chat Place 0.1.6

An update to 0.1.5, still a pre-release. If you have 0.1.5 installed, it offers this update itself
(Help, Check for Updates asks at once), and your sessions and settings are kept.

## Added

- **Find in All Sessions.** View, Find in All Sessions (Ctrl+Shift+S) searches the messages of
  every session in the list, for when you can't remember which session you talked about
  something in. It lists each message found with its session, who wrote it, when, and the words
  around the match; Enter loads that session on that message. It says how many sessions it
  searched and how many it couldn't read. (#109) (#199)
- **Change a session's permission mode and effort.** File, Change Permission Mode
  (Ctrl+Shift+O) switches one of The Chat Place's own sessions between auto, accept edits,
  manual and plan, from its next turn. New Session has a new **Effort** box (Alt+E): Default
  (your Claude Code setting), Low, Medium, High, Extra high or Max, and File, Change Effort
  changes it later. Models that don't support effort levels ignore it. The session's heading now
  says its effort and mode, when they aren't the defaults, along with its model. Desktop app and
  terminal sessions are still set in Claude or the terminal. (#189) (#196)
- **A list of the links in a session.** View, Links (Ctrl+L) lists every link in the loaded
  session's messages, newest first, each read as its words, where it goes, who wrote it and
  roughly when ("release notes, github.com/…/tag/v0.1.5. Claude, 3 messages ago"). Enter opens
  one in your browser; Ctrl+C copies its address, and Copy as Markdown (Ctrl+Shift+C) the whole
  link. Type to narrow the list. Only web, email and session links open; anything else, such as a
  file path, can be copied. It works from the session list, the messages and the reply box.
  (#190) (#198)

## Changed

- **Last activity follows what Claude is doing.** In the session list, a session working through
  a long turn, or being run outside The Chat Place, used to read "active 3 hours ago": the time
  the turn began. Last activity is now the last time the session did anything, so it reads
  "active just now" while Claude works. A new **Started** column, which you can add in View,
  Session List Columns (Alt+V, E), says when each session began. (#209)

## Fixed

- **New Session and Continue Here show their fields whole.** In File, New Session (Ctrl+N), the
  Folder box is as wide as the other boxes, with Browse and From GitHub under it rather than
  beside it, so more of a long path shows. In File, Continue Here (Ctrl+Shift+N), the Title box shows
  the start of the title rather than its end, and the About continuing box is tall enough for its
  whole note. (#178)
- **The status bar's buttons show their whole text.** The buttons at the right of the status
  bar (how full the context is, sessions that need you, an update) were too short for their
  text, so the bottoms of letters such as y and g were cut off. The status bar is now a little
  taller to fit them. (#175)
- **Long text no longer runs off the edge of the window.** Several lines of text were too long
  for their windows and were cut off at the right edge:
  - In Settings, the Remote Control check box.
  - In Help, Report a Bug, the note giving the support email address.
  - In View, Session List Columns, the explanation at the top.
  - In View, Usage and Context, the first line.
  - In the main window, the heading above the messages when a session's title is long.

  They now wrap onto more lines, or the window is wide enough for them, and screen readers read
  them as before. Settings and Claude's questions no longer leave a large empty space above their
  buttons. (#176)
- **A first run says how to start.** With no sessions at all, the messages used to say to choose
  one from the session list, which was empty. Now they say there are no sessions yet, and that
  File, New Session (Ctrl+N, or Cmd+N on a Mac), the Claude desktop app or a terminal starts
  one. (#182)
- **Show Tool Activity is set for each session.** Turning on View, Show Tool Activity (Ctrl+T) to
  see one session's tool calls used to show them in every session. Now it applies only to the
  loaded session, and it's remembered: the session shows its tool activity again the next time you
  load it, and the others stay as they were. (#162) (#194)
- **Code blocks keep their outline in High Contrast.** In a message read as a formatted page,
  in Help, User Guide, and in a session exported as a web page, a code block was marked only by a
  light grey background. High Contrast themes remove background colours, so the block ran into
  the text around it. It now has a border in the theme's text colour there. In dark mode, the
  page's scroll bar is dark too, to match the page. (#155) (#188)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you
exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs
   access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to
   [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

The same files as 0.1.5: TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and
TheChatPlace-macos-arm64.dmg, with the update feeds. See the
[user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and
the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

The same as 0.1.0: Windows 10 or 11, or a Mac with Apple silicon, and Claude Code installed with
its native installer and signed in to a Claude subscription. See the 0.1.0 release notes for the
details.
