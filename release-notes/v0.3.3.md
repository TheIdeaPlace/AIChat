# The Chat Place 0.3.3

An update to 0.3.2, still a pre-release. When released, installed copies offer this update and keep your sessions and settings.

## Added

- **Linux (preview).** The Chat Place now runs on Linux PCs, x64 and Arm: download `TheChatPlace-linux-x64.AppImage` or `TheChatPlace-linux-arm64.AppImage`, make it executable and run it. Its first start adds it to your desktop's menu, and it updates itself like the Windows and Mac apps. Orca reads it, and announcements are spoken through Orca. Alt or F10 opens the menu bar. Thanks to @aaron-gh for the port. (#230)
- **Back up your chats.** Your Claude, Codex and Copilot conversations, memory and settings are kept on this computer, and signing in on a new one doesn't bring them back. File, **Back Up Now** saves them all in one file in a folder you choose, with The Chat Place's own groups, names and hidden chats. Another drive or a cloud folder is best. Backing up, checking and restoring work in the background without taking focus: the status bar (Ctrl+9) shows what's happening, and a message says when they're done. (#433)
- **Encrypted backups.** Back Up Now asks for a passphrase. With one, the whole backup is encrypted, file names included. The passphrase isn't kept anywhere, so if you forget it, nobody can open the backup. (#435)
- **Backups on a schedule.** File, **Backup Schedule** backs up by itself every day or every week while The Chat Place is open, keeping as many as you choose. They can be encrypted too: the passphrase is kept where your computer protects it, so the schedule can use it with nobody there. (#437) (#442)
- **Check a backup.** File, **Check Backup** reads a backup back and says whether every file in it is whole. (#433)
- **Restore from a backup.** File, **Restore from Backup** brings a backup's chats back into the session list, on this computer or a new one. Choose which ones: Space switches each between Restore and Skip. They come back in their groups (hidden ones hidden), and read-only: you can read, find and export them, not continue them. Restoring the same backup again updates them instead of adding copies. (#436) (#450)
- **Chats Claude deletes stay readable.** Claude Code deletes its chats after a while (30 days unless you change it). The Chat Place now keeps its own copy of each Claude chat it lists, so a chat Claude deletes stays in the list, read-only. Settings (Ctrl+Comma) shows how long each AI keeps chats, under History (Alt+Y). (#438)
- **Continue Here for Copilot chats.** File, Continue Here (Ctrl+Shift+N) now carries on a chat started in Copilot CLI or another app: a new Copilot chat of your own in the same folder. Copilot can't copy a chat, so your first message goes with the conversation so far, your messages and Copilot's replies but not the commands it ran. It takes no extra request: only the first message's own. In the copy, the conversation so far is one row, "Earlier conversation", before your message. The original chat isn't changed. (#423)
- **Choose a Copilot chat's model.** In New Session (Ctrl+N), Model now lists the models Copilot offers you, each with the premium requests a message costs, such as "GPT-5 (1x)", and File, **Change Model** changes a Copilot chat's model from its next turn; the chat's heading says which model it's on. Copilot lists its models only for a chat, so New Session offers them once you've opened a Copilot chat here. (#422)
- **Plan mode for Copilot chats.** A Copilot chat can now start in Copilot's plan mode, where it works out a plan and doesn't edit your files: choose Plan under Permission mode in New Session (Ctrl+N) or Continue Here (Ctrl+Shift+N), or switch a chat between agent and plan mode with File, Change Permission Mode (Ctrl+Shift+O), as Shift+Tab does in Copilot CLI. Copilot still asks before anything that needs your permission, and the chat's heading says when it's in plan mode. (#424)
- **`/wrap` and other session commands work in Claude chats started here.** Claude now has the session tools those commands and skills use in the desktop app: it can list the sessions in The Chat Place's list, look one up and search their messages. Archiving a chat started here hides it, as File, Hide Session does, and File, Bring Back Session returns it. Desktop app sessions are never changed: Claude says to archive them in the desktop app. (#165)

## Changed

- **New keys in Settings.** Turn on Remote Control is now Alt+U and Include GitHub Copilot CLI chats is Alt+I. Their old keys, Alt+C and Alt+O, were also the Cancel and OK buttons' on a Mac and on Linux. (#438)
- **Questions open on their text.** When a chat asks you a question, Answer (Ctrl+Shift+A) now opens on a Question box you can read by line, with what the chat wrote just before asking, such as a draft it wants you to approve, and each question in full. When a choice comes with a preview, a Preview box after the questions shows the preview of the choice you're on. (#415)

## Fixed

- **Stopping a Copilot chat.** Pressing Stop (Ctrl+Period) again no longer gives Copilot more time to stop, and says Copilot was already asked. Stopping before your message has gone to Copilot no longer warns that Copilot will be closed; the message comes back unsent. (#405) (#414)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip, TheChatPlace-macos-arm64.dmg, TheChatPlace-linux-x64.AppImage and TheChatPlace-linux-arm64.AppImage, with the update feeds. See the [user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
