# The Chat Place 0.1.7

An update to 0.1.6, still a pre-release. The big change: **you can now talk to Codex in The Chat Place**, alongside Claude, in the same list, with the same keys. If you have 0.1.6 installed, it offers this update itself (Help, Check for Updates asks at once), and your sessions and settings are kept.

## Added

### Codex in The Chat Place

- **Talk to Codex here.** If Codex is installed on your computer (the Codex app, the ChatGPT app on a Mac, or the Codex command-line tool, even if only Codex's own installer put it in your .codex folder) and signed in to ChatGPT, your Codex chats appear in the session list automatically. Read them, find and export their messages, or start one: File, New Session (Ctrl+N; Command+N on a Mac) now lets you choose Claude or Codex. Send messages, queue more while Codex works, and Stop it, just as with Claude. You can turn Codex chats off in Settings. (#255) (#277) (#283) (#294)
- **Choose what Codex may change.** A new Codex chat can edit files in the folder you choose and asks before anything else. You can also choose read-only. File, Change Permission Mode (Ctrl+Shift+O; Command+Shift+O on a Mac) changes it for a chat that isn't working. Continue Here starts its copy read-only. Codex can't be given write access to your whole home folder or a whole drive. (#255)
- **Folder editing on Windows needs Codex's Windows sandbox.** Until it's set up (Set up Agent sandbox in the Codex app, or `sandbox = "unelevated"` under `[windows]` in Codex's config.toml), Codex can only read, and The Chat Place tells you so instead of starting a folder-editing chat. If a new Codex chat can't be started, your first message is kept, in the open chat's message box or on the clipboard. (#257) (#292) (#299)
- **Answer Codex when it needs you.** When Codex asks permission or asks a question, you hear what it wants and get a desktop notification. Answer (Ctrl+Shift+A; Command+Shift+A on a Mac) answers it. Turn Status (Ctrl+Shift+T) says what Codex is doing and for how long. (#255)
- **Let Codex reach past its folder when you say so.** When Codex names extra access, such as writing to Git's `.git` folder, another folder or the network, Answer lists it under "This also needs" and names the host for network access. When it names none, Answer says the command may run outside the chat's folder, with access to all your files. You get only the one-time answers Codex offers for that request: Allow Once, Deny, or Deny and Stop Turn. Nothing is allowed for longer than that one request, and Codex's "always allow" rules are never saved. A request The Chat Place can't show is still declined, and the chat says which kind and why. (#284) (#295)
- **Know when your saved Codex rules apply.** Commands you've told Codex to always allow still run without asking, even outside the chat's folder and with network access. New Session and Change Permission Mode say so, and Properties shows how many rule files are in effect. Rules that come inside a project folder are refused, because you never chose them. (#257) (#272) (#292) (#299)
- **Codex usage and context.** View, Usage and Context shows your ChatGPT limits, what's left and when they reset, and how full the chat's context is. You're warned once at 80% and at 100%. (#255)
- **Choose Codex's model and effort** when you start or continue a Codex chat. Continuing an older Codex chat
  whose model OpenAI has since retired can fail with a "model is not supported" message; start a new chat
  instead. (#255) (#302)
- **Every session row says which AI it is.** The Provider column (Claude or Codex) is on by default, read right after the title. Kind still says where the chat started. Remove or move either in View, Session List Columns. (#271)

### Also new

- **Lists: code blocks, links, changed files, commands and decisions in one place.** View, Lists
  (Ctrl+Shift+I; Command+Shift+I on a Mac) lists each kind, for the selected message or the whole
  chat. Commands lists each command Claude ran, with what it was for, whether it worked, and its
  output. Decisions lists each question Claude asked you, with your answer. Choose the kind in the
  Kinds list, or from anywhere with Ctrl+Tab on Windows and Command+Shift+] on a Mac. Code Blocks
  (Ctrl+Shift+B), Links (Ctrl+L) and Changed Files (Ctrl+Shift+D) now open Lists on their kind.
  In Codex chats, Lists has Code Blocks and Links for now; the other kinds say they aren't listed yet.
  (#279) (#280) (#282) (#303)
- **Formatted pages on a Mac.** Return on a message, Keyboard Shortcuts (F1), the User Guide and a plan's Read Formatted button now open a formatted page on a Mac too, as they do on Windows. VoiceOver's rotor and its heading and table commands move through it, so tables read by cell. Option+P switches to plain text, and Escape or Command+W closes it. (#119) (#268)

## Changed

- **Rows and dialogs name the AI.** Answer, New Session and message dialogs cover Claude and Codex. Claude desktop app rows now say "desktop app session" in the Kind column. (#255)
- **Codex chats stay safe when you switch chats or stop.** Moving to another chat never interrupts a running turn. Long replies and large file changes no longer break the connection; very long output is shortened on screen, and the full history stays available. A message is never resent without you. (#247) (#255)

## Fixed

- **Mac hints name the keys that work.** Spoken prompts, dialogs and Help say Command, Option and Return on a Mac, and Help names the File, View or Help menu. (#246) (#274)
- **/compact now tells you it happened.** You hear it and see "Conversation compacted" in the chat, with how much context was freed, even with tool activity off. Output from commands like /context and /cost now appears in the chat too. (#249) (#275)
- **Claude Code's sign-in is read even with terminal codes around it.** Help, Claude Code Sign-in no longer says it "Couldn't tell whether Claude Code is signed in" when Claude Code adds terminal control codes to its answer. (#222)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

The same files as 0.1.6: TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and TheChatPlace-macos-arm64.dmg, with the update feeds. See the [user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, or a Mac with Apple silicon. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. You need only the one you use.
