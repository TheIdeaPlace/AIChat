# The Chat Place 0.1.7

An update to 0.1.6, still a pre-release. If you have 0.1.6 installed, it offers this update itself
(Help, Check for Updates asks at once), and your sessions and settings are kept.

## Added

- **Live Codex token reports and context warnings.** Usage and Context shows the
  latest model request separately from cumulative token use. A reported context
  window enables its percentage in the status bar and a queued 80% warning that
  resets after compaction. Missing reports remain unknown. (#225)

- **Let Codex edit files in its folder.** New Session defaults to folder editing
  with on-request approvals, and offers read-only. File, Change Permission Mode
  (Ctrl+Shift+O) changes an idle owned Codex chat. The selected scope is verified
  and saved before sending; existing chats keep their permissions. (#225)

- **Read Codex account usage in TCP.** View, Usage and Context (Ctrl+Shift+U)
  reads current used/remaining allowances and reset times in the background.
  Missing values are shown as not reported. (#225)

- **Read local Codex chats alongside Claude chats.** Settings,
  Include local Codex chats turns on the preview after restarting. A native Codex
  CLI is required. Select a Codex chat to read, find or export its history. New Session
  offers Codex as a Provider, and Continue Here makes an owned copy of an existing chat.
  Owned chats support text replies, Stop, queued messages and Answer (Ctrl+Shift+A)
  for one-time permissions and questions. Sent messages follow the existing
  read-back setting; Turn Status reports elapsed time and latest activity, and
  returned queued messages are announced. View, Show Sessions can filter by
  Claude or Codex, and Session List Columns distinguishes Provider from Kind. Last message
  also fills Codex rows in cached background batches. (#225)

- **Choose a Codex model and reasoning effort.** New Session and Continue Here load the
  available choices in the background. Effort follows the selected model, and configured
  defaults remain available. Selections are rechecked before starting the chat. (#225)

- Codex account-limit warnings follow owned turns at 80% and 100%, once per
  allowance/reset window, and queue behind read-back. Missing usage stays
  unreported rather than showing zero. (#225)

## Changed


- **Shared controls name the provider or use neutral wording.** Answer, New Session, message
  dialogs, empty-list guidance, About and the user guide cover Claude and Codex together.
  Claude-specific features keep their names. (#225)

## Fixed

- Unsupported Codex requests are declined explicitly without disconnecting
  other work. A notice names the request category and Turn Status keeps it
  available. Answer can reach a waiting Claude chat while you read Codex. (#247) (#225)

- Large Codex command-output bursts no longer fill the reply/approval queue
  and interrupt the connection. Connection failures give a safe, specific
  reason in speech, Turn Status and the session list. After a disconnect,
  Stop can reconnect once native history confirms the previous turn ended;
  it never resends your message or resumes over unfinished work. (#247) (#225)

- Revisiting a Codex chat preserves its running connection. TCP checks saved
  chats for unfinished turns before resuming, and a refused pre-send check
  no longer closes other chats' running connections. Codex working status
  no longer cuts off sent-message read-back. (#247) (#225)

- **Codex work and drafts are protected during updates and quitting.** Active replies and
  permission waits prevent an update restart, unsent Codex drafts trigger the warning, and
  quitting asks before stopping running work from either provider. (#225)

- **The session list stays useful during a discovery failure.** Previously listed chats stay
  available, with a notice that they may be out of date. F5 reports a continuing outage. (#225)

- **Claude Code's sign-in is read even with terminal codes around it.** Help, Claude Code Sign-in
  no longer says it "Couldn't tell whether Claude Code is signed in" when Claude Code adds
  terminal control codes to its answer. (#222)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you
exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs
   access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to
   [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

The same files as 0.1.6: TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and
TheChatPlace-macos-arm64.dmg, with the update feeds. See the
[user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and
the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, or a Mac with Apple silicon. For Claude chats, install native Claude Code
and sign in to a Claude subscription. For the Codex preview, a native Codex CLI signed in to
ChatGPT is required. Claude Code is not required for Codex chats.
