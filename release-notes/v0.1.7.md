# The Chat Place 0.1.7

An update to 0.1.6, still a pre-release. If you have 0.1.6 installed, it offers this update itself
(Help, Check for Updates asks at once), and your sessions and settings are kept.

## Added

- Settings offers an opt-in local Codex history preview. Read, find, export and
  filter Codex chats alongside Claude chats, using a native Codex CLI signed in
  to ChatGPT. Codex chats are read-only in this preview. Restart after changing
  the setting. (#254)

## Fixed

- **Claude Code's sign-in is read even with terminal codes around it.** Help, Claude Code Sign-in
  no longer says it "Couldn't tell whether Claude Code is signed in" when Claude Code adds
  terminal control codes to its answer. (#222)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you
exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs
   access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to
   [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

The same files as 0.1.6: TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and
TheChatPlace-macos-arm64.dmg, with the update feeds. See the
[user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and
the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

The same as 0.1.0: Windows 10 or 11, or a Mac with Apple silicon, and Claude Code installed with
its native installer and signed in to a Claude subscription. See the 0.1.0 release notes for the
details.
