# The Chat Place 0.1.7

An update to 0.1.6, still a pre-release. If you have 0.1.6 installed, it offers this update itself
(Help, Check for Updates asks at once), and your sessions and settings are kept.

## Added

- **Formatted pages on a Mac.** Return on a message, Help, Keyboard Shortcuts (F1), Help, User
  Guide and a plan's Read Formatted button now open a formatted page on a Mac too, as they do on
  Windows. VoiceOver's rotor and its heading and table commands move through it, so a reply with
  tables reads by cell instead of as rows of pipes. Option+P switches to plain text, and Escape or
  Command+W closes the page. (#119) (#268)
- **Know when saved Codex rules apply.** Your own and your computer's saved rules
  stay in effect. New Session and Change Permission Mode explain that always-allow
  commands may run outside the folder without asking; Properties counts rule files.
  Rules supplied by a project are refused before starting or sending. (#257) (#272)

- **Start a Codex chat and talk to it here.** File, New Session (Ctrl+N; Command+N
  on a Mac) offers Codex when Include local Codex chats is enabled in Settings.
  Restart after changing that setting. Read existing local chats, find and export
  their messages, or start one here to send replies and queue more work. (#255)
- **Choose file access for Codex.** New Session defaults to editing files in its
  selected folder and asking when additional access is needed. Read-only is also
  available. File, Change Permission Mode changes an idle chat started here;
  existing chats keep their saved choice. Continue Here creates a read-only copy
  unless you select folder editing. Broad folders such as home cannot be writable. (#255)
- **Answer Codex permissions and questions.** Answer (Ctrl+Shift+A; Command+Shift+A
  on a Mac) handles the loaded chat first, then another waiting chat. Short request
  summaries and desktop notifications tell you when Codex needs you. Turn Status
  reports its latest activity and elapsed time. Replies and warnings wait for
  sent-message read-back to finish. (#255)
- **Read Codex usage and context.** View, Usage and Context shows account limits,
  remaining percentages and reset times, plus the latest reported model request's
  tokens separately from its cumulative total. A reported context window enables
  a percentage and an 80% warning. Account warnings arrive at 80% and 100%, once
  until the limit resets. Missing reports stay unknown. (#255)
- **Choose Codex model and effort when starting or copying a chat.** Available
  choices load in the background; configured defaults remain available. Later
  Change Model and Change Effort commands currently apply to Claude chats. (#255)
- **Keep Codex work safe when switching chats or stopping.** Selecting a chat
  preserves its running turn. Stop returns queued text; pressing it again can
  check an ended turn if the completion message never arrived. Connection recovery
  never resends a prompt. Large live output is shortened for display; full history
  remains available. Unsent messages and drafts are protected during quitting. (#255)

- **Provider is a regular default session-list column.** It says which AI; Kind
  remains on and says where the session started. Existing custom columns gain
  Provider immediately after Title, or first if Title is hidden, without losing
  their other choices or order. Remove it in View,
  Session List Columns if you prefer; it stays removed after saving. (#184) (#271)

- **Lists: code blocks, links, changed files, commands and decisions in one place.** View, Lists
  (Ctrl+Shift+I; Command+Shift+I on a Mac) lists each kind, for the selected message or the whole
  chat. Commands lists each command Claude ran, with what it was for, whether it worked, and its
  output. Decisions lists each question Claude asked you, with your answer. Choose the kind in the
  Kinds list, or from anywhere with Ctrl+Tab on Windows and Command+Shift+] on a Mac. Code Blocks
  (Ctrl+Shift+B), Links (Ctrl+L) and Changed Files (Ctrl+Shift+D) now open Lists on their kind.
  (#279) (#280) (#282)

## Changed

- **Shared controls name the provider.** Answer, New Session, message dialogs and
  help cover Claude and Codex together. Kind now says "desktop app session" for
  Claude desktop rows; Provider identifies which AI. Claude-specific features
  retain their names. (#255)

## Fixed

- **Mac shortcut hints name the keys that work.** Spoken prompts, dialog labels
  and Help use Command, Option and Return. User text and conversation titles are
  kept as written. The published guides explain both platforms' key names. (#246) (#274)

- **Hear and see when Claude compacts a chat.** Conversation compacted stays in
  the messages list with tool activity off, and its announcement waits for message
  read-back. Reported token counts update Usage and Context. Local command output
  such as `/context` and `/cost` appears as Claude Code messages too. (#249) (#275)

- **Claude Code's sign-in is read even with terminal codes around it.** Help, Claude Code Sign-in
  no longer says it "Couldn't tell whether Claude Code is signed in" when Claude Code adds
  terminal control codes to its answer. (#222)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you
exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs
   access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to
   [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

The same files as 0.1.6: TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and
TheChatPlace-macos-arm64.dmg, with the update feeds. See the
[user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and
the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, or a Mac with Apple silicon. For Claude chats, install native Claude Code
and sign in to a Claude subscription. For the Codex preview, a native Codex CLI signed in to
ChatGPT is required. Claude Code is not required for Codex chats.
