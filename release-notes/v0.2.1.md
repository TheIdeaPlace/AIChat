# The Chat Place 0.2.1

An update to 0.2.0, still a pre-release. When released, installed copies offer this update and keep your sessions and settings.

## Added

- **What Codex knows about you.** View, What AI Knows About You (Ctrl+Shift+K) now has a Provider list (Alt+V) for Claude or Codex. Read Codex's local instructions, memories, skills, saved prompts and settings with the same lists and file actions as Claude. This shows local customization files, rather than account-wide memory or a turn's active context, and never reads Codex's sign-in or chat history. (#305) (#371)

- **Agent conversations.** File, New Agent Conversation (Ctrl+Shift+G) puts two chats, Claude and Codex or two of either, in one conversation with you, and passes each one's replies to the other. This is the second phase of chat-to-chat messaging that 0.2.0's Send Reply to Another Chat began. Use your own chats or start new ones, and give each a role, such as builder and reviewer. The conversation is one row in the session list, and its messages list has both agents' messages in order, each naming who said it. You approve each hand-off with Ctrl+Shift+E, or, once you turn it on in Settings, replies go across by themselves up to a turn limit (6 by default). Approving what an agent asks, such as running its tests, doesn't stop automatic hand-offs. It also stops when an agent says it's done once the others have replied (its last reply can still be handed on), when the replies start repeating or are only thanks, or when you refuse something an agent asks or leave it unanswered. Before automatic hand-offs start, you're asked first if either provider is near a usage limit, and File, Agent Conversation Hand-offs can make automatic mode say only when it stops or needs you. Usage and Context (Ctrl+Shift+U) shows both agents. Enter on the relay's lines reads exactly what was sent, including the setup each agent got. Address one agent with @ and its name, or its name and a comma: "Codex, check the tests". Permissions and questions still come to you from each agent, and a message from one agent can never answer or approve anything for the other. (#248) (#347) (#348) (#349)
- **Kinds of agent conversation, a third agent, and the files that changed.** In New Agent Conversation, Kind of conversation fills in the roles, new chats' permissions and who goes first for a builder and reviewer, a second opinion, a debate, or plan and do. An optional third agent joins in turn, and each agent is sent the replies it missed along with the one passed to it. A reply passed on ends with the files its agent changed in that turn, so a reviewer knows what to look at. (#248) (#350)
- **GitHub Copilot CLI chats, read-only.** Settings, **Include GitHub Copilot CLI chats** (Alt+O) lists the sessions GitHub Copilot CLI keeps on this computer alongside your other chats, and View, Show Sessions, **GitHub Copilot Chats** lists only them. Read, find and export them, hear when one finishes answering, and turn on Show Tool Activity to hear the commands Copilot ran. Reading never starts Copilot or uses your Copilot requests. Reply in Copilot CLI for now. The setting appears once Copilot CLI has saved a session on this computer; restart after changing it. (#352) (#355)

## Changed

- **A full message starts with who wrote it, as a heading.** Read Full Message (Enter on a message) now opens with "Claude" or "Codex" as heading 1, so H or 1 takes you to the top of the message, and the message's own headings sit under it. The screen reader no longer says "Message: Claude, main region" before the message. (#341) (#346)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and TheChatPlace-macos-arm64.dmg, with the update feeds. See the [user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, or a Mac with Apple silicon. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. For GitHub Copilot chats (read-only preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
