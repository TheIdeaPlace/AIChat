# The Chat Place 0.6.4

This pre-release offers Fable in subscription chats on Max and Ultra plans. Installed copies offer it as an update and keep your sessions and settings.

## Added

- **Fable in subscription chats on Max and Ultra.** New Session and Chat, Chat Settings, Change Model (Alt+C, N, M) now offer Fable when Claude Code is signed in to a Max or Ultra plan, which include a Fable allowance. On Pro, or a plan The Chat Place doesn't recognize, Fable still isn't offered, because every Fable message would be charged to usage credits. (#722)
  - **It stops where usage credits would start.** If usage credits are on and a Fable turn goes past your plan's Fable allowance, The Chat Place stops the turn as soon as Claude Code says it's being charged to usage credits. It then asks **Use usage credits?**: Keep Going (one more turn on usage credits), Change Model, or Leave Stopped.
  - **It asks every time.** Once turns are being charged to usage credits, sending to a Fable chat asks first, and the answer is never remembered. A queued message isn't sent on usage credits; it comes back to your message box.
  - **A Fable you didn't choose is still stopped**, as before: Claude Code's own default model, or a fallback to Fable.

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip, TheChatPlace-macos-arm64.dmg, TheChatPlace-linux-x64.AppImage and TheChatPlace-linux-arm64.AppImage, with the update feeds. See the [user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription (or an Anthropic API key, for chats on API credits). For Claude in Chrome: the Claude in Chrome extension in Chrome or Edge. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT (or an OpenAI API key, for chats on API credits). For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
