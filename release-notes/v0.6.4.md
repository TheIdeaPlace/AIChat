# The Chat Place 0.6.4

This pre-release offers Fable in subscription chats on Max and Ultra plans, and adds Muse Code: help setting it up, its conversations in your session list, and Muse Code chats of your own that run here. Installed copies offer it as an update and keep your sessions and settings.

## Added

- **Fable in subscription chats on Max and Ultra.** New Session and Chat, Chat Settings, Change Model (Alt+C, N, M) now offer Fable when Claude Code is signed in to a Max or Ultra plan, which include a Fable allowance. On Pro, or a plan The Chat Place doesn't recognize, Fable still isn't offered, because every Fable message would be charged to usage credits. (#722, #724)
  - **It stops where usage credits would start.** If usage credits are on and a Fable turn goes past your plan's Fable allowance, The Chat Place stops the turn as soon as Claude Code says it's being charged to usage credits. The request that went past it may be charged.
  - **Then it asks every time you send.** Sending to a Fable chat asks **Use usage credits?**: Use Usage Credits (for that one turn), Change Model, or Cancel. The answer is never remembered. Queued messages and agent conversations aren't sent on usage credits; they come back with the reason.
  - **A Fable you didn't choose is still stopped**, as before: Claude Code's own default model, or a fallback to Fable.

- **Console output you paste becomes a code block.** Paste (Ctrl+V) text copied from a
  console window, such as a command and its error, into the reply box or New Session's First
  message, and it goes in as a code block with the console's padding spaces trimmed, so it
  reads as code in every view, whichever AI the chat uses. You hear that it was pasted as a
  code block. Ordinary text pastes as it is.

**Muse Code**

- **Muse Code setup.** Tools, **Sign In**, **Muse Code** checks installation and
  sign-in, shows status, errors and installation instructions in standard OK dialogs, and
  helps you sign in and check again. You run the installer yourself.
- **Read Muse Code conversations.** Stored Muse chats appear when Muse Code is
  installed. View, Show Sessions, **Muse Code Chats** filters the list. Open a chat
  with Enter to read, copy, find or export messages. Conversations started
  outside The Chat Place stay read-only. Failed refreshes keep the last
  good history available. An item Muse Code shortened says so where it is,
  and only history that can't be read at all gives a warning.
- **Start Muse Code chats here.** File, New Session offers Muse Code when it is
  installed, with Model, Effort and Permission mode after Title to choose the
  model, effort and permission profile it starts on (Muse Code's own model and
  Ask me unless you choose others). The new chat runs here: it streams replies, and announces each
  pending request with its chat title, even while you read another chat.
  Ctrl+Shift+A offers Muse Code's one-time Allow once or Reject for a
  request (Reject also ends the turn), or answers its questions. Muse's Ask
  me permissions prompt for restricted actions; safe actions can run without
  asking. Stop waits for confirmed cancellation, and you hear whether a turn
  finished or stopped. In the Status column, a chat started here says
  Working, Needs you or Idle. Chats Muse Code started elsewhere stay read-only.
- **Muse Code chats have the Chat menu's commands.** Steer (Ctrl+Alt+Enter)
  sends a message into a running turn. Chat, Chat Settings, Change Model and
  Change Effort switch the chat to another model or effort Muse Code offers,
  and Change Permission Mode (Ctrl+Shift+O) switches between Muse Code's Read
  only, Ask me, Auto-review and Unrestricted, asking first before the last
  two. Insert Command or Skill (Ctrl+/) lists the chat's Muse Code skills, and
  a message starting with one runs it. Attach Files (Ctrl+Shift+F) sends
  images and files with your next message. Ask Aside (Ctrl+Shift+Y) asks a
  read-only side question; Muse Code keeps each side chat in its own list, and
  The Chat Place hides them from yours. Retry from Here (Ctrl+Shift+Z) makes a
  new chat from before one of your messages, with the message ready to change
  and send, and Branch from Here makes one through a message's whole turn.
  Tools, Usage and Context (Ctrl+Shift+U) says how full a chat's context is and
  its last turn's tokens, with your Muse Code plan, for every Muse Code chat.
  Stop Background Task stops one piece of background work and lets the turn
  carry on.
- **Muse Code's background work.** For bigger jobs, such as reviewing a
  whole code base, Muse Code starts a workflow whose sub-agents keep working
  after its reply. You hear that it's working in the background, each
  sub-agent's permission request is announced (Ctrl+Shift+A answers it), and
  you hear Muse Code's reply when the work is done. Meanwhile the chat's
  Status is Working, and Needs you while a sub-agent waits for your answer.
  The conversation shows the workflow and each sub-agent's task. A command
  Muse Code leaves running after its reply, such as a test suite, keeps the
  chat Working in the same way until it ends.
- **Long command output no longer stops a Muse Code turn.** A command that
  prints a lot, such as a full test suite, could end Muse Code partway
  through the turn, leaving its permission request where you couldn't answer
  it and the chat saying Idle. Muse Code now carries on.
- **Muse Code 1.4.24.** The Chat Place works with Muse Code 1.4.24, the
  first version where a command you allow runs in Muse's sandbox on Windows.
  With 1.4.20 it doesn't run, because Muse reports that its sandbox is
  unavailable. To update Muse Code, run `muse` in a terminal: it updates
  itself.
- **When a Muse Code command is denied on Windows.** Muse's sandbox runs
  commands as a separate Windows account, so a command such as `python` from
  the Python install manager fails with "Access is denied", and Git can refuse
  the folder as "dubious ownership". The user guide's Troubleshooting, Muse
  Code, says how to fix both: a virtual environment in the chat's folder, and
  Git's `safe.directory` setting. (#701)

## Changed

- **Bug reports say why chats couldn't be listed.** When the list says
  Codex, Copilot or Muse Code "discovery unavailable", The Chat Place now
  notes the kind of problem, such as Muse Code not answering in time. Help,
  **Report a Bug** includes those notes for the last day, so a report can say
  what went wrong. As before, they never include your folders, messages or
  the other app's own error text.

## Fixed

- **A command in inline code shows as code, not a file link.** In a reply, a command in
  backticks, such as `winget install Kitware.CMake`, or a program named on its own, such as
  `app.exe`, was made a link to a file in the chat's folder that wasn't there. It now shows
  as code. A full path, such as `C:\Tools\app.exe`, is still a file link. (#701)

- Pressing **F5** no longer says Codex or Muse Code "discovery unavailable"
  when their chats are only still being refreshed. That takes a second or
  two, and the list now says it only when listing them actually failed.

- An empty **Muse Code Chats** view now explains that no conversations were
  found and how to refresh after starting one in Muse Code. Pressing Enter in
  that empty list repeats the guidance. A pending or failed history check is
  identified separately.

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription (or an Anthropic API key, for chats on API credits). For Claude in Chrome: the Claude in Chrome extension in Chrome or Edge. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT (or an OpenAI API key, for chats on API credits). For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. For Muse Code chats: Muse Code, signed in to a Meta account. You need only the one you use.
