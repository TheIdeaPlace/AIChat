# The Chat Place 0.6.4

This pre-release offers Fable in subscription chats on Max and Ultra plans, and fixes copying from a formatted message and Go to Status Bar on a Mac. Installed copies offer it as an update and keep your sessions and settings.

## Added

- **Fable in subscription chats on Max and Ultra.** New Session and Chat, Chat Settings, Change Model (Alt+C, N, M) now offer Fable when Claude Code is signed in to a Max or Ultra plan, which include a Fable allowance. On Pro, or a plan The Chat Place doesn't recognize, Fable still isn't offered, because every Fable message would be charged to usage credits. (#722, #724)
  - **It stops where usage credits would start.** If usage credits are on and a Fable turn goes past your plan's Fable allowance, The Chat Place stops the turn as soon as Claude Code says it's being charged to usage credits. The request that went past it may be charged.
  - **Then it asks every time you send.** Sending to a Fable chat asks **Use usage credits?**: Use Usage Credits (for that one turn), Change Model, or Cancel. The answer is never remembered. Queued messages and agent conversations aren't sent on usage credits; they come back with the reason.
  - **Tools, Usage and Context (Ctrl+Shift+U) lists your weekly Fable limit** once a Fable turn has run, and keeps it there after turns on other models. Past your limits, it says "Turns are now charged to usage credits."
  - **A Fable you didn't choose is still stopped**, as before: Claude Code's own default model, or a fallback to Fable.
- **Express: the latest reply from every chat in one list.** Turn it on with View, Express (Alt+V, X) or in Settings. A row at the top of the session list opens a list of your chats, newest first, each with its name, provider and latest reply. Enter opens a chat, Shift+Enter reads its whole reply, and R replies to it in a box named for that chat, so you can check on several chats without opening each one. It covers the chats the session list is showing, up to 10 at first (Settings sets how many). (#737, #741)

## Changed

- **Help, About says which build you're running.** After the version, it gives the commit it was built from and the date, so you can always tell one copy from another, for example "0.6.4 (commit 1512fbe2 on v0.6.4, built 2026-11-27)". Bug reports include the same line. (#735)

## Fixed

- **Copying from a formatted message works on a Mac.** Pressing Enter on a message opens it as a formatted page. Selecting text there and pressing Command+C now copies it. Before, nothing was copied, and an "Error running JavaScript" message appeared. (#725)
- **Go to Status Bar (Command+9) works with VoiceOver.** VoiceOver now moves to the status bar and reads what it says. Left and Right move between its parts. Before, VoiceOver said "Go to Status Bar" but stayed where it was. (#726)
- **Number boxes' up and down arrows have names with VoiceOver.** In Settings, Backup Schedule and an agent conversation's turn limit, Tab stops on the arrows beside a number, and VoiceOver now says what they change, for example "Backups to keep". Before, it said only "stepper". (#726)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip, TheChatPlace-macos-arm64.dmg, TheChatPlace-linux-x64.AppImage and TheChatPlace-linux-arm64.AppImage, with the update feeds. ## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription (or an Anthropic API key, for chats on API credits). For Claude in Chrome: the Claude in Chrome extension in Chrome or Edge. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT (or an OpenAI API key, for chats on API credits). For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
