# The Chat Place 0.6.3

This pre-release lets Claude use your browser with Claude in Chrome, and can suggest what to send next after a reply. Installed copies offer it as an update and keep your sessions and settings.

## Added

- **Claude in Chrome works in Claude chats.** Claude can open pages in Chrome or Edge, read them, fill in forms and click, as it can in the Claude desktop app. You need the Claude in Chrome extension installed and signed in to the same claude.ai account as Claude Code. (#319)
  - **It's on from each chat's next message,** in new chats and ones you already have, on your subscription. **Settings, "Let Claude use Chrome"** turns it off or on. Until you change it, it's on if Claude Code has found the extension.
  - **Each website asks your permission first,** for example "Claude in Chrome wants to navigate on example.com". **Allow for This Chat** lets it use that site for the rest of the chat. In Auto mode, sites Claude Code judges safe may not ask.
  - **The tabs Claude opens stay with the chat,** so it finds them again on your next message, as long as Chrome stays open.
  - **It isn't available in chats on API credits,** because Claude Code keeps it off with an API key. Claude says so, rather than sending you to a setting.
- **Suggested messages.** After a reply, Claude can suggest what you might send next. Turn it on with **Settings, "Suggest what to send next after each reply"**; it's off at first. (#474)
  - **The suggestion is put in your empty message box, selected,** and a new sound, **Prompt suggested**, plays. With sounds off or muted, you hear "Prompt suggested" instead. Type to replace it, or press Ctrl+Enter to send it as it is. Not every reply has one.
  - **Your own text is never replaced.** If you've typed something or have a draft, the suggestion isn't put in.
  - **Claude chats on your subscription only.** Chats on API credits don't ask, since each suggestion is an extra request the reply's cost wouldn't include. Codex and Copilot don't offer suggestions to other apps yet.
  - **It needs a recent Claude Code.** 2.1.326 sends suggestions; 2.1.286 doesn't. Run `claude update` in a terminal if none come.
- **A sound at the end of a list.** With sounds on, Up or Home on the first row of the session list or the messages list, or Down or End on the last, plays **Reached the end of a list**, the same sound QuickMail plays at the end of its lists. Before, the key seemed to do nothing. It's in the built-in schemes; in a scheme of your own, choose a sound for it in Tools, Sounds. (#714)

## Fixed

- **Codex chats say plainly that the browser isn't available here.** Codex's browser, its browser extension, computer use and Codex Cloud work only in OpenAI's own apps. Codex chats in The Chat Place, including reopened chats and copies, are now told so, so if you ask for the browser, Codex says it can't rather than trying. Browser tools you've added yourself as MCP servers still work. (#524, #708)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip, TheChatPlace-macos-arm64.dmg, TheChatPlace-linux-x64.AppImage and TheChatPlace-linux-arm64.AppImage, with the update feeds. ## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription (or an Anthropic API key, for chats on API credits). For Claude in Chrome: the Claude in Chrome extension in Chrome or Edge. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT (or an OpenAI API key, for chats on API credits). For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
