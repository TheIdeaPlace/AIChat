# The Chat Place 0.1.10

An update to 0.1.9, still a pre-release. When released, installed copies offer this update and keep your sessions and settings.

## Added

- **Remember Codex Git approvals in this chat.** Choose Allow for This Chat in Answer (Ctrl+Shift+A) to approve matching Git commands without asking again, including after a restart. Review or remove approvals in File, Chat Permissions (Ctrl+Shift+H). Removal applies before the next approval is sent. These commands have the same authority as Allow Once; the dialog explains their access. Your Codex and Claude settings stay unchanged. (#307)
- **See the commands Codex already allows.** For a Codex chat, Chat Permissions (Ctrl+Shift+H) now lists the rules in Codex's own saved rule files in its About box (Alt+T): each command Codex runs without asking, always asks about, or never allows, and the file it's in. These are the commands you told Codex to always allow, and they apply to every Codex chat. Before, only the number of rule files was shown. When a request can't be kept for the chat, Answer now says so. (#307)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and TheChatPlace-macos-arm64.dmg, with the update feeds. See the [user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, or a Mac with Apple silicon. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. You need only the one you use.
