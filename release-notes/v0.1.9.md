# The Chat Place 0.1.9

An update to 0.1.8, still a pre-release. If you have 0.1.8 installed, it offers this update itself, and your sessions and settings are kept.

## Multi Provider Support

With The Chat Place now supporting both Claude and Codex, every effort will be made to support features in both AI providers with the same UI. As features are added however, it may not always be possible to add them for both providers at the same time. I will work to reduce this from happening and when a new feature is added, will indicate when it currently works with only one provider. A future update's release notes will also detail gaps of existing features between the two currently supported providers.

## Added

- **Task lists for Claude and Codex.** View, Tasks (Ctrl+Shift+J) lists each step as to do, in progress or done. Turn Status and Properties report progress, and Full-level announcements name newly completed steps. Claude task lists also work for desktop and terminal sessions; Codex task lists are captured for chats run here and kept when you reopen them or send another message. Codex task lists from earlier sessions or other apps aren't available. Settings, "Let Claude keep a task list" controls Claude chats started here. (#231) (#318)
- **Chat Permissions.** File, Chat Permissions (Ctrl+Shift+H) shows what a chat started here may do without asking. (#307) (#332) (#336)
  - **Its permission mode,** with Change.
  - **What you've allowed for this chat** with Allow for This Chat: each rule, and any folder kept with it, with when you allowed it. Remove (or Delete) takes one back, and Remove All takes them all.
  - **Rules from Claude Code's own settings** that apply to the chat's folder, read only, each with its file. They apply to every Claude session in that folder; change them in Claude Code.
  - **For a Codex chat,** the permission mode and how many of Codex's own saved rule files are in effect. The Chat Place doesn't keep Codex approvals yet, so each Codex request still asks.

  The user guide's new section, "Permissions: what a chat may do without asking", explains every level: Allow (this request only), Allow for This Chat (kept with the chat), the permission mode, and Claude Code's own settings.

## Changed

- **Allow for this session is now Allow for This Chat** when Claude asks permission, because the rule lasts for the whole chat, and File, Chat Permissions lists it. (#332)
- **Allow for This Chat keeps what Claude asked about, not a whole new mode.** For a command that writes, such as `mkdir`, it used to switch the chat to accepting all file edits. It now keeps that command's rule and the folder it works in, as the button's name says, so the next turn doesn't ask again for it. Claude can then work in that folder as in the chat's own. Both appear in File, Chat Permissions (Ctrl+Shift+H), where you can remove them. (#334)

## Fixed

- **What Claude Knows About You lists everything once.** If you had ever run a Claude session from your home folder, View, What Claude Knows About You showed each of your skills, subagents, slash commands and settings a second time, prefixed with your user name. Each now appears once. (#315) (#316)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip and TheChatPlace-macos-arm64.dmg, with the update feeds. See the [user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, or a Mac with Apple silicon. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. You need only the one you use.
