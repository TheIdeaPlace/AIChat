# The Chat Place 0.6.1

This pre-release adds setup assistance, conversation history and app-created chats for Muse Code. It offers itself as an
update to installed copies of The Chat Place.

## Added

- **Muse Code setup.** Tools, **Sign In**, **Muse Code** checks installation and
  sign-in, shows status, errors and installation instructions in standard OK dialogs, and
  helps you sign in and check again. You run the installer yourself.
- **Read Muse Code conversations.** Stored Muse chats appear when Muse Code is
  installed. View, Show Sessions, **Muse Code Chats** filters the list. Open a chat
  with Enter to read, copy, find or export messages. Conversations started
  outside The Chat Place stay read-only. Failed refreshes keep the last
  good history available. Unsupported or incomplete history is identified.
- **Start Muse Code chats here.** File, New Session offers Muse Code when it is
  installed. The new chat runs here: it streams replies, announces each
  pending request with its chat title, even while you read another chat.
  Ctrl+Shift+A offers Muse Code's one-time Allow once or Reject for a
  request (Reject also ends the turn), or answers its questions. Muse's Ask
  Steer (Ctrl+Alt+Enter) sends a message into a running turn, and Chat, Chat
  Settings, Change Model and Change Effort switch the chat to another model or
  effort Muse Code offers. Insert Command or Skill (Ctrl+/) lists the chat's
  Muse Code skills, and a message starting with one runs it. Ask Aside
  (Ctrl+Shift+Y) asks a read-only side question; Muse Code keeps each side
  chat in its own list, and The Chat Place hides them from yours. Attach
  Files (Ctrl+Shift+F) sends images and files with your next message. Change
  Permission Mode (Ctrl+Shift+O) switches between Muse Code's Read only, Ask
  me, Auto-review and Unrestricted, and asks first before the last two.
  Retry from Here (Ctrl+Shift+Z) makes a new chat from before one of your
  messages, with the message ready to change and send, and Branch from Here
  makes one through a message's whole turn.
  me policy prompts for restricted actions; safe actions can run without
  asking. Stop waits for confirmed cancellation, and you hear whether a turn
  finished or stopped. Chats Muse Code started elsewhere stay read-only.
  With Muse Code 1.4.20 on Windows, a command you allow doesn't run yet:
  Muse reports that its sandbox is unavailable. This is a known Muse Code
  problem, not a setting in The Chat Place.

## Fixed

- An empty **Muse Code Chats** view now explains that no conversations were
  found and how to refresh after starting one in Muse Code. Pressing Enter in
  that empty list repeats the guidance. A pending or failed history check is
  identified separately.

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip, TheChatPlace-macos-arm64.dmg, TheChatPlace-linux-x64.AppImage and TheChatPlace-linux-arm64.AppImage, with the update feeds. See the [user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. For Muse Code chats: Muse Code, signed in to a Meta account. You need only the one you use.
