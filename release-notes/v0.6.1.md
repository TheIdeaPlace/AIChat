# The Chat Place 0.6.1

This pre-release fixes problems with Codex chats, and a few smaller ones. Installed copies offer it as an update and keep your sessions and settings.

## Fixed

- **Long messages to Codex now go through.** Codex takes at most 32,000 characters in a message. A longer one, such as a pasted build log, used to fail, and as a new chat's first message it left a chat showing "status unavailable" for good. Now The Chat Place saves the message to a temporary file and asks Codex to read it there. Attached pictures still go with it. You hear that it was given to Codex as a file, and in the chat it reads as your message, labeled "You, sent as a file". The file is deleted when Codex's turn ends. (#625)
- **A Codex chat that Codex no longer has now says so.** Opening a chat that was deleted in Codex, or one created here whose first message was never sent, used to say its turn status was uncertain. Now you hear that Codex no longer has the chat, and that Session, Delete Session Permanently removes it from the list. (#625)
- **Codex chats made with another model provider are listed.** If you changed Codex's model provider in its settings, chats you'd made in Codex with the previous one dropped out of the session list, and their subagents out of Tools, Subagents. Now every provider's chats are listed, to read. Continue Here, Branch from Here, Retry from Here and Ask Aside don't copy a chat made with a provider other than ChatGPT into a ChatGPT chat; they say so instead. (#644)
- **Renaming the open session updates the window title.** After Session, Rename Session (F2), the window title still had the old name, which is what Alt+Tab and your screen reader's read-title key say. It now changes straight away. (#553, #645)
- **An "&" in a chat's title now shows.** The heading above the messages and the Messages label left it out, so "Salt & pepper" read "Salt pepper". (#539, #645)
- **An empty session list says so.** When the session list had nothing in it, or Find Sessions matched nothing, screen readers read "unknown" there. Now you hear "No sessions". (#621)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Downloads

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip, TheChatPlace-macos-arm64.dmg, TheChatPlace-linux-x64.AppImage and TheChatPlace-linux-arm64.AppImage, with the update feeds. See the [user guide](https://github.com/TheIdeaPlace/AIChat/blob/main/docs/user-guide.md) to get started, and the [README](https://github.com/TheIdeaPlace/AIChat#readme) for everything The Chat Place does.

## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
