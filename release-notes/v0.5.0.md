# The Chat Place 0.5.0

The Chat Place 0.5 lets you go back to an earlier message and try again, ask a quick question about a chat without adding to it, read a whole chat as one page, and hear what a chat is doing through sounds. Claude and Codex chats both gain subagent conversations, connected tools, chat options and more, and Codex chats gain most of what Claude chats already had.

An update to 0.4.0, still a pre-release. Installed copies offer this update and keep your sessions and settings.

Keys below are written for Windows. On a Mac, use Command for Ctrl. The Alt keys here are for Windows and Linux.

## Added

- **Go back or try another way, in Claude and Codex chats.** Select one of your messages and press Ctrl+Shift+Z (File, **Rewind to Here**) to start a new chat from just before it, with that message in the reply box ready to change and send. **Branch from Here**, on a message's menu (Shift+F10), starts a new chat from that point. The original chat is kept. In Codex, a branch includes the whole turn the message is in, and a copy can't change files without asking until you press Ctrl+Shift+O (File, **Change Permission Mode**) in it, as you hear when it opens. It doesn't keep the original's model, effort, Chat Options or connected tools. On a Mac, Rewind to Here is Command+Shift+Z in the messages. (#467) (#468) (#600)
- **Put files back, in Claude chats.** Rewind to Here can also put back the files Claude changed with its edit tools, or only the files. It works in Claude chats started here, for messages sent with this version on. Each file goes back to the last version Claude Code saved, so edits you made by hand since Claude last changed it are lost, even ones from before that message, and there's no undo. Changes made by commands, and files only a subagent changed, don't go back. The dialog opens on **Conversation only**, names the files, and says when files can't go back. (#468)
- **Ask Aside, in Claude and Codex chats.** Ctrl+Shift+Y (File, **Ask Aside**) asks a quick question about a chat without adding the question or the answer to it, even while the chat is working. It answers from the chat up to its last finished reply. Ctrl+Enter asks, and the answer is read out and goes in the Answer box. Follow-ups know the earlier answers, and a chat's questions stay listed until you quit or choose **Clear List** (Alt+R). It can only read files, and each question uses your plan as a message does. (#467) (#468) (#559)
- **Read a whole chat as one page.** Ctrl+Shift+W (View, **Read Full Chat as a Web Page**) opens every message in the chat on one page, starting at the message you're on. Each message is a heading, so you move between them by heading level 2. Alt+P shows it as plain text instead, and Escape takes you back. (#538)
- **Sounds.** Hear what a chat is doing without tool activity on. The Chat Place has its own sound for each of 23 events, such as a tool running, a file changing, a reply finishing, another chat finishing, an agent conversation passing a reply on by itself, a chat needing you, your answer to it going, a message you steer into a running turn, and a queued message you remove. Sounds that belong together are alike, so a new one is easy to place. They're off until you turn them on in File, **Sounds**, where you choose the volume, a scheme (Glass, Soft bell or Wood, the same sounds in a different tone), which chats make tool sounds and which make the others, and any event's sound, including a WAV file of your own. **Space** on an event plays its sound. **Ctrl+Shift+X** (View, **Mute All Sounds**) silences everything. This is a first version: please tell us which sounds help, which don't, and what's missing. (#250) (#581) (#588) (#590) (#599)
- **Sound schemes of your own.** In File, **Sounds**, **Scheme Actions** (Alt+A) makes a new scheme, or copies, renames, deletes or resets one, and exports or imports a scheme as a `.tcpsounds` file with its sound files. Each scheme keeps its sound files in its own folder, and deleting a scheme deletes them. **Browse Gallery** (Alt+B) lists schemes others have shared, ready to add: for now Essentials, only the sounds you'd otherwise miss, and River Voicing Glass, where each sound is followed by a voice saying what happened. (#250) (#589)
- **Sound Tutorial.** Help, **Sound Tutorial** lists every sound event by name. Press **Space** or **Enter** on one to hear its sound in the scheme you use, even with sounds off. (#250) (#582)
- **Subagents, in Claude and Codex chats.** View, **Subagents** (Alt+V, G), or Ctrl+7 in Lists on Windows, shows the work handed to each subagent: its prompt, how it's going and its report. Enter opens its conversation, where Enter reads a message, Ctrl+C copies it and Ctrl+T shows tool activity. Messages arrive as it works, and you hear when it finishes. A turn's message menu also has **Subagent Conversations**, and Changed Files says which subagent changed a file. A Codex subagent's requests say which subagent is asking. (#468) (#521)
- **Connected tools.** View, **Connected Tools (MCP)** lists a chat's MCP servers, and claude.ai connectors or Codex apps, with how each is doing. **Sign In** opens the sign-in page (for Codex, after reading you its real address), and **Reconnect** tries a failed tool again. In a Claude chat started here, **Turn Off for This Chat** keeps a tool out of later turns. In a Codex chat started here, tools start off and can't be changed in the chat itself: **Copy with Tool On** or **Copy with Tool Off** (Alt+O) makes a new copy of the chat with that choice, after asking, and the original keeps its tools. Sign In says what to do when it can't sign in here. Add servers in Claude Code or Codex, not here. (#468) (#467) (#554) (#360) (#601)
- **Answer a connected tool's questions.** When a connected tool asks for something while Claude or Codex works, the chat needs you. **Answer** (Ctrl+Shift+A) shows its message and a form to fill in, or a web page to open, with an **Address** box that says where the page really goes. A form The Chat Place can't show can be declined, or left waiting. (#468) (#525) (#599)
- **Chat Options, for Claude and Codex.** **Chat Options** (Alt+H) in New Session and Continue Here, and File, **Chat Options** for a chat started here, set instructions for this chat and more folders it may work in. For Claude, you can also choose an agent to run the chat as and an output style. An agent with its own model says so, and one whose model could bill usage credits is refused. Changes to a chat apply from its next message. (#468) (#527)
- **Stop one background task.** File, **Stop Background Task** lists running background work and stops just the one you choose, leaving the turn and the rest running. In Codex, `/background` opens the same list. (#467) (#468) (#600)
- **Thinking and the context breakdown.** With **Show Tool Activity** on (Ctrl+T), a Claude chat shows Claude's thinking when Claude Code saves it, and a Codex chat shows Codex's reasoning summaries. **Usage and Context** (Ctrl+Shift+U) lists how much of Claude's context the system prompt, tools, memory files, skills and messages use, and how much is left. (#468) (#555)
- **Hear when the AI is retrying.** When Claude's or Codex's service is busy or can't be reached, you hear it's retrying, such as "Claude is retrying: the service is busy.", and **Turn Status** (Ctrl+Shift+T) has the details. You also hear when Claude switches to another model for a turn, and, at the Full announcement level, when it saves a memory. (#468) (#556) (#599)
- **Attach files in Codex chats, and paste files.** **Attach Files** (Ctrl+Shift+F) now works in Codex chats too: pictures reach Codex as images, and other files are named for it to read. In Claude and Codex chats, Ctrl+V in the reply box now attaches files you copied in File Explorer or the Finder, as well as a picture. Delete in the attachment list removes one, and queued messages keep theirs. (#467)
- **Codex commands and skills.** **Insert Command or Skill** (Ctrl+/) lists the skills turned on for the chat's folder, and Codex's controls. Choosing a skill puts its name in the reply box and sends the skill with your message. The controls are `/plan` to switch between Codex's **Plan** and **Default** modes, `/compact` to shorten an idle chat's context, `/model` and `/reasoning`, `/memories on` and `/memories off`, `/goal` to read, pause or clear a Goal set in Codex, and `/background`. (#467) (#600)
- **Session tools for Codex.** A Codex chat started here can list, search and read the chats in The Chat Place's list, and hide an idle one, as Claude chats could in 0.4. It can't hide itself, an open chat or one that's working. (#557)
- **Every approval in a Codex chat, in one list.** Lists (Ctrl+Shift+I) has a new **Approvals** kind (Ctrl+8 on Windows): each request Codex's automatic review allowed or didn't, and each one Allow for This Chat allowed, newest first, with the reason. Copy copies the command. File, **Chat Permissions** (Ctrl+Shift+H) lists them newest first too. (#564) (#600)
- **Choose where a new worktree's branch starts.** In New Session (Ctrl+N), with **Work in** set to A new worktree and a new branch name, **Start from** (Alt+A) chooses the remote's main branch, fetched first, or what the folder has checked out. You hear what was made. When Claude moves a chat into a worktree, the chat follows and you hear where it went, and Properties (Alt+Enter) lists its branch and worktree. (#561)
- **Getting more out of Claude, Codex and Copilot.** New parts of the user guide (Help, **User Guide**) start from situations you might be in, such as wanting to agree on an approach first or repeating yourself, and say what would help and where it is. (#546)

## Changed

- **Change a Codex chat's model or effort.** File, **Change Model** and **Change Effort** now work on an idle Codex chat started here, from its next message. Change Effort's first choice, like Model's and Effort's in New Session, is **Codex's default**. (#467) (#600)
- **Change Claude's model or permission mode during a turn.** File, **Change Model** and **Change Permission Mode** (Ctrl+Shift+O) now change the running turn too, when Claude Code can, and you hear "now and for later turns". You also hear when Claude changes the mode itself, such as "Claude switched to plan mode." If Claude switches to plan mode, the chat stays in plan mode. If you change the mode from your phone over Remote Control to one that asks less, that lasts only for that turn. (#468) (#599)

## Fixed

- **Shift+Enter starts a new line in an answer.** In the Answer dialog (Ctrl+Shift+A), Shift+Enter in your own answer to a question, in a plan's What to Change box or in a reason for Deny now starts a new line instead of sending. In a one-line box, such as a secret answer or a connected tool's form, Shift+Enter no longer sends either. Enter still sends. (#591)
- **A chat you've answered says it's working.** After you answer a chat that needed you, the messages list now says the chat is working when you're back in it, instead of still saying it needs you. This is for Claude, Codex and Copilot chats, and agent conversations. (#599)
- **Branches already checked out aren't missing from New Session.** With **Work in** set to A new worktree, **Branch** (Alt+R) now lists branches checked out in another worktree or in the folder itself, last, saying so, such as "main (in use in another worktree)". Pressing Start with one says where it's checked out and how to work from it, such as a new branch started from origin/main. (#587)
- **Automatic approvals no longer bury a Codex chat.** Requests that Codex's automatic review or Allow for This Chat allows are now shown and spoken only with **Show Tool Activity** on (Ctrl+T), like tool calls. A request that isn't allowed is still shown and spoken. (#564)
- **Desktop app and Cowork sessions are back.** The Microsoft Store version of the Claude desktop app moved its data to a new folder, so The Chat Place stopped finding those sessions and their groups, and backups left them out. It now looks in both places, and lists each chat once. (#542)
- **Quitting during a turn.** A chat or agent conversation you quit in the middle of a turn now says it was stopped when you come back, and nothing queued starts as the app closes. (#545)
- **Continue Here keys.** Tab now stops on the Folder box, and the Browse and GitHub buttons no longer open when the folder can't change. (#467) (#468)
- **New Session keys.** When Model, Effort, Permission mode or Branch is turned off, as with Copilot, its Alt key no longer jumps to the next setting. (#515)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
