# The Chat Place 0.5.0

Planned for the feature release after the release currently in preparation. This is still a pre-release. When released, installed copies will offer this update automatically.

## Added

- **Go back or try another approach in Claude and Codex chats.** Select one of your messages and press Ctrl+Shift+Z (File, **Rewind to Here**) to start a new chat from just before it, with that message ready to change and send. **Branch from Here**, on a message's menu, starts a new chat from that point. The original chat is kept. In Codex, a branch includes the whole turn containing the selected message or reply, and both actions leave files unchanged. Codex copies start read-only, with its configured model and effort and connected tools off. (#467) (#468)
- **Restore files in Claude chats.** Rewind to Here can restore the conversation, the files Claude changed, or both. File restoration works in Claude chats started here, for messages sent with this version onward. It restores changes made with Claude's edit tools; changes made by commands or subagents aren't restored. The dialog names the files and says when restoration isn't available. (#468)
- **Ask Aside with Claude or Codex.** Ctrl+Shift+Y (File, **Ask Aside**) asks a quick question about a chat without adding the question or answer to it, even while the main chat is working. Ctrl+Enter asks; the answer is read out and goes in the Answer box. It uses a temporary copy that can only read files, with commands and connected tools off. Each question uses your provider's plan, as a message does. (#467) (#468)
- **Files, pictures and screenshots in Codex chats.** **Attach Files** (Ctrl+Shift+F) adds files or images to your next message, and Ctrl+V in the reply box attaches a picture on the clipboard. Pictures reach Codex as images; other files are named for it to read. Queued messages keep their attachments. Delete in the attachment list removes one before sending. (#467)
- **Codex commands and skills.** **Insert Command or Skill** (Ctrl+/) offers enabled skills for the chat's folder and controls for its model, effort, Plan mode, compaction, memories, Goal status and background terminals. Choosing a skill adds its name and sends the skill with your next message. A control is handled here rather than sent as a prompt. (#467)
- **Codex's native Plan mode.** Choose `/plan` from the command picker to switch between **Plan** and **Default** for later turns. The heading says when Plan is selected. Planning mode keeps the chat's permission settings; choose Default when you're ready for it to carry out the plan. (#467)
- **Compact a Codex conversation.** `/compact` asks Codex to shorten the context of an idle chat. After changing the chat's settings, send a normal message before compacting so Codex has applied those settings. (#467)
- **Codex memories and Goal controls.** `/memories on` and `/memories off` choose whether this chat uses and contributes to Codex memories. `/goal` reads its saved Goal and usage; `/goal pause` pauses it and `/goal clear` removes it. Starting or resuming autonomous Goals isn't available in The Chat Place yet. (#467)
- **Choose connected tools for Codex.** View, **Connected Tools (MCP)** lists configured MCP servers. **Copy with Tool On/Off** asks before making a new read-only chat with the chosen tool selection; the original keeps its selection. Enabled tools can access external services beyond the chat's folder, so enable only servers you trust. Add servers and sign in through Codex CLI. Apps, plugins and connected-tool question forms aren't available for Codex here yet. (#467)
- **See and manage Claude's connected tools.** View, **Connected Tools (MCP)** lists MCP servers and claude.ai connectors, with their connection status. **Sign In** opens the sign-in page, **Reconnect** tries a failed tool again, and **Turn Off for This Chat** keeps a tool out of that chat's later turns. When a turn starts with a tool Claude can't use, you hear it once. (#468)
- **Answer a connected tool's questions in Claude chats.** When an MCP server or connector asks for something while Claude works, the chat needs you. **Answer** (Ctrl+Shift+A) shows its message and a form to fill in, or a web page to open. (#468)
- **Stop one background task with either provider.** File, **Stop Background Task** lists running background work and lets you stop just the selected task, keeping the turn and other work going. In Codex, `/background` opens the same list of terminals. (#467) (#468)
- **See the work Claude hands to subagents.** View, **Subagents** (Alt+V, G), or Ctrl+7 in Lists, shows each subagent's prompt, progress and final report. Enter opens its conversation; Enter reads a message in full, Ctrl+C copies it and Ctrl+T shows tool activity. Messages arrive as a subagent works, and you hear when it finishes. A turn's message menu also offers **Subagent Conversations**. Changed Files includes subagents' changes and says which subagent made them. (#468)
- **Chat options for Claude.** **Chat Options** (Alt+H) in New Session and Continue Here, and File, **Chat Options** for a Claude chat started here, choose an agent to run the chat as, instructions for this chat, an output style and more folders Claude may work in. Changes to an existing chat apply from its next message. (#468)
- **Hear when Claude is retrying.** When its service is busy or unreachable, you hear the attempt and when the next retry is; **Turn Status** (Ctrl+Shift+T) keeps the details. You also hear when Claude switches to another model for a turn, and, at the Full announcement level, when it saves a memory. (#468)
- **Read Claude's thinking and context breakdown.** With **Show Tool Activity** on (Ctrl+T), the conversation includes thinking where Claude kept the text. **Usage and Context** (Ctrl+Shift+U) lists how much context the system prompt, tools, memory files, skills and messages use, and how much space remains. (#468)

## Changed

- **Change a Codex chat's model or effort after starting it.** File, **Change Model** and **Change Effort** now work on an idle Codex chat started here. Choices come from Codex; the verified, saved choice applies from the next message. (#467)
- **Change Claude's model or permission mode during a turn.** File, **Change Model** and **Change Permission Mode** now apply to the running turn too, when Claude supports it, and you hear "now and for later turns". If Claude switches to plan mode by itself, the chat stays in plan mode for its next turns. (#468)

## Reporting Issues

Found a problem or have a suggestion? Help, **Report a Bug** fills in a report and shows you exactly what it includes before it goes anywhere: never your session titles, folders or messages.

1. **Open on GitHub** copies the report and opens a new GitHub issue with it filled in. This needs access to the repository.
2. **Copy Report** puts the report on the clipboard, to email to [support@theideaplace.net](mailto:support@theideaplace.net).

TheChatPlace-windows-Setup.exe, TheChatPlace-windows-Portable.zip, TheChatPlace-macos-arm64.dmg, TheChatPlace-linux-x64.AppImage and TheChatPlace-linux-arm64.AppImage, with the update feeds. ## Requirements

Windows 10 or 11, a Mac with Apple silicon, or a Linux PC (x64 or arm64) at least as new as Ubuntu 24.04, Debian 13 or Fedora 40, with FUSE 2 to run the AppImage (`sudo apt install libfuse2t64`) and Orca and speech-dispatcher for speech. For Claude chats: Claude Code, signed in to a Claude subscription. For Codex chats: the Codex app, the ChatGPT app or the Codex command-line tool, signed in to ChatGPT. For GitHub Copilot chats (preview): GitHub Copilot CLI, signed in to an account with Copilot. You need only the one you use.
